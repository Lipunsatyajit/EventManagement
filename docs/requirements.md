# Utkal Events Requirements

Source: `Odisha_Event_Planner_Master_Requirements_v1(1).pdf`

## Purpose
Marketplace for discovering event planners in Odisha, reviewing portfolios, and requesting consultations.

## Vision
- Discover planners.
- View portfolios and completed events.
- Request consultations.
- Support offline payments in v1.

## Roles
- Super Admin
- Event Planner
- Customer

## Business Flow
Search by district -> Planner profile -> Completed events -> Login -> Consultation request -> Planner notification -> Offline discussion -> Review
